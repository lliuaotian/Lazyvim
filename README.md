# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Dependencies

- git
- luarocks
- compat-lua (Provides Lua 5.1 for Nvim's luarocks dependencies)
- lazygit (if you need git tui)
- fzf
- python3-pip
- pynvim
- make cmake (Other commonly used commands will not be listed one by one)
- blink.cmp (This plugin may require uninstalling it once in Lazy and restarting nvim twice more)

## Extras

Recommended:
  - ai.avante
  - test.core
  - coding.yanky
  - dap.core
  - editor.inc-rename
